# Yasora Markdown Studio — راهنمای فارسی

این پروژه یک پوسته گرافیکی متن‌باز برای موتور **Microsoft MarkItDown** روی ویندوز، مک و لینوکس است. کد پروژه توسط Yasora-Labs توسعه داده می‌شود و به Microsoft وابسته یا منتسب نیست.

**وضعیت فعلی:** کد و سیستم ساخت نسخه‌های نصبی آماده شده است، اما فایل‌های واقعی `Setup.exe`، `DMG`، `DEB` و `APK` هنوز با سیستم‌های عامل مربوطه ساخته و تأیید نشده‌اند. بستهٔ سورس را با فایل نصب اشتباه نگیرید.

## نصب برای کاربران پس از انتشار نسخهٔ تأییدشده

- ویندوز: اجرای `Yasora-Studio-Windows-x64-Setup.exe`؛ ساخت میانبر Start Menu و منوی راست‌کلیک اختیاری.
- مک Apple Silicon و Intel: دریافت DMG مناسب پردازنده و انتقال اپلیکیشن به Applications.
- لینوکس Debian/Ubuntu x64: نصب فایل `.deb`.
- اندروید: نصب APK امضاشده؛ فعلاً موتور بومی اندروید امکانات محدودتری دارد و تبدیل PDF/OCR در آن انجام نمی‌شود.

برنامه دسکتاپ همهٔ کتابخانه‌های موردنیاز خودش را همراه دارد و برای کاربر نهایی نصب Python، uv یا VS Code لازم نیست. خروجی به‌صورت پیش‌فرض در پوشه Documents با نام `Yasora Markdown Studio` ذخیره می‌شود.

## آپدیت

دکمه Check Updates اطلاعات نسخهٔ موتور روی PyPI و نسخهٔ برنامه در GitHub Releases را بررسی می‌کند. به‌دلیل امنیت و سازگاری فایل نصب، نسخهٔ موتور مستقیماً داخل بستهٔ منجمد PyInstaller تعویض نمی‌شود؛ توسعه‌دهنده پس از تست یک بستهٔ جدید منتشر می‌کند و کاربر آن را نصب می‌کند.

## توسعه و ساخت فایل‌های نصبی

مخزن `Yasora-Labs/Yasora-Markdown-Studio` باید ساخته شود، سورس به آن منتقل شود و Workflow موجود در Actions اجرا شود. تا زمانی که بیلدها و تست سیستم‌عامل‌ها موفق نشده‌اند، ریلیز در حالت Draft می‌ماند. راهنمای انگلیسی `README.md` و چک‌لیست `docs/RELEASE_CHECKLIST.md` را ببینید.
